## 📦 Instalação

Siga os passos abaixo para rodar o projeto localmente:

### Clone o repositório
git clone https://github.com/JoaoGW/ProjetoChatBot.git

### Acesse o diretório do projeto
cd ProjetoChatBot

### Instale as dependências
npm install
ou
yarn install

### Inicie o servidor de desenvolvimento
npm run dev
ou
yarn dev
